Autonomous Vehicle Route Simulator is a software project that simulates how self-driving vehicles navigate from a starting point to a destination. The system uses a virtual road network to find suitable routes, avoid obstacles, and display the vehicle's movement.

The simulator can demonstrate route planning, pathfinding, obstacle avoidance, traffic conditions, and vehicle movement in a safe virtual environment. Algorithms such as A* or Dijkstra’s algorithm can be used to calculate efficient routes.

Key features:

🚗 Simulates autonomous vehicle movement
🗺️ Creates and displays road networks
📍 Selects source and destination points
🧭 Finds an efficient route automatically
🚧 Handles obstacles and blocked roads
🚦 Can simulate traffic or road conditions
📊 Displays route and vehicle status
🔄 Allows real-time route updates

Project objective:
To create a virtual environment for understanding and testing autonomous vehicle navigation and route-planning algorithms without requiring a real vehicle.
